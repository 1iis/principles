# Terms
> Human, machine, operator, synth

We need two distinctions, not one.

1. **Kind**: what something **is**.
2. **Role**: what something **does**.

A human is a biological person.
A machine is a technical artifact.
An operator is whatever controls an action.
A target is whatever the action changes.

For most of history, these distinctions overlapped so strongly that we confused them. The operator was human; the machine was operated; the target was the thing being changed.

| operator | machine | target |
| --- | --- | --- |
| drummer | drum | rhythm |
| archer | bow | arrow |
| driver | car | route |
| user | computer | file |

The thing now called “AI” breaks that habit.

A machine can now occupy the operator role. It can call tools, write code, drive software, select actions, transform files, and operate other machines.

We call such a system a **synth**: a synthetic operator.

> **A synth is  
machine by kind,  
operator by role.**

This avoids stretching old words too far. A synth is not a person, not a user, not an assistant in the human sense, and not merely a passive tool. It is a machine with operator-capability.

```
              OPERATOR
    controls / acts through tools
                  ↑
                  |
human  ←——————————+——————————→  synth
biological        |             synthetic
person            ↓             machine-agent
               TARGET
        acted on / transformed
```

So the basic vocabulary becomes:

| Word | Meaning |
| --- | --- |
| person | biological moral subject |
| machine | technical substrate |
| operator | role: controls action |
| target | role: receives action |
| synth | synthetic operator; machine capable of operator-role behavior |

The important split is therefore not human versus machine, nor user versus AI, but:

| kind | role |
| --- | --- |
| human | operator |
| synth | operator |
| machine | target/instrument |
| world/file/system | target |

A human and a synth can then form a compound operator: a human-synth pair, each contributing alien strengths to one shared course of action.
